# Number Guessing Game

Welcome to the Number Guessing Game! This is a command-line based game where you can challenge yourself to guess a randomly selected number within a certain number of attempts. The game includes different difficulty levels, a timer, hints, and the ability to track your high scores.

## Features

- **Random Number Generation:** The computer selects a random number between 1 and 100.
- **Difficulty Levels:** Choose from three difficulty levels:
  - **Easy:** 10 chances
  - **Medium:** 5 chances
  - **Hard:** 3 chances
- **Guessing Mechanism:** Receive feedback indicating if your guess is too high or too low.
- **Multiple Rounds:** Play as many rounds as you'd like.
- **Timer:** See how long it takes to guess the correct number.
- **High Score Tracking:** Keep track of your best performance.

## How to Play

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/ishamgit/guessing_game_cpp.git


 Navigate to the project directory:

cd number-guessing-game

Compile the game using g++:

g++ guessing_game.cpp -o guessing_game

Run the game:

./guessing_game


Game Rules

When you start the game, a welcome message will be displayed along with the rules.
Select a difficulty level which determines your number of chances.
Enter your guess when prompted.
The game ends when you correctly guess the number or when you run out of chances.
